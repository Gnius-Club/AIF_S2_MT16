📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a realizar una sesión de playtesting de la escape room de un compañero. Guíame para escribir feedback claro y constructivo y luego usar un LLM para analizar el sentimiento de mi propio texto. Después ayúdame a reflexionar si el tono de mi feedback coincide con mi intención y cómo podría mejorarlo."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El análisis de la IA coincide con lo que realmente querías expresar?
  • ¿Qué pasa si usas palabras sarcásticas en tu feedback?
  • ¿Funciona igual el análisis con un texto muy corto vs uno muy largo?
  • ¿Cómo ayuda el playtesting a identificar problemas de UX que no habías visto antes?
  • ¿De qué manera el análisis de sentimiento permite una mejora continua más objetiva en un producto?

¡Es hora de crear y poner a prueba nuestras habilidades! Vamos a realizar una sesión de playtesting real. El flujo es sencillo: primero ideen con XOLO cómo evaluarán el trabajo de un compañero, definan un VIBE para su feedback y luego usen el GCS que XOLO les dará para analizar el sentimiento de sus palabras. Por ejemplo, podrían evaluar si una escape room es demasiado difícil o muy divertida y ver si la IA capta esa emoción. No olviden las preguntas de experimentación para ver cómo cambia el análisis si cambian sus palabras. Al terminar, asegúrense de cerrar sus sesiones. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar su análisis.
